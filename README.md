# الذكاء الاصطناعي لمنصة مقايضة المواد الخام

نسخة تطوير لمنصة B2B في مصر. مش جاهزة للبرودكشن. مناقشة الجمعة ٢٧ نوفمبر ٢٠٢٦ نقطة مراجعة، والشغل على الجاهزية مكمل بعدها.

## تنبيه مهم عن الرؤية

التدريب وجمع صور جديدة وإعادة بناء بيانات الرؤية متوقفين بسبب أخطاء في سلامة البيانات والتقييم. ادعاءات إن كل الصور مصرية وإن التقسيم خالٍ من التسريب اتسحبت. مفيش حاليًا رقم رؤية معتمد للإنتاج، ولا حد ترقية مبني على الأرقام القديمة.

اقرأ SCORECARD.md للحالة الحالية، وvision/evaluation/README.md للأدلة وتاريخ التغييرات. مجموعة التحقق القديمة محفوظة بشكل مستقل في vision/evaluation/legacy62_v1 ومعاها بصمات الصور والتسميات والأوزان. ده حفظ للأدلة، مش اعتماد لجودتها.

## المكونات

- ner/: استخراج الخامة والكمية والمكان باستخدام SpaCy. F1 الداخلي 0.9877 على جمل مولّدة، مش إعلانات حقيقية مستقلة.
- pricing/: XGBoost على 195 صف سعر منشور. MAPE الزمني 7.21% لخامات معروفة، والتحقق المتقاطع 26.12%. الحكم محدود بالخامة والحالة المدعومتين.
- vision/: أوزان YOLOv8 محفوظة للتجربة، مع إيقاف التدريب والترقية. التعرف البصري على جديد/مستعمل/صدأ مش مدعوم.
- chatbot/: بحث دلالي وFAISS على 600 إعلان مولّد، مش مخزون تجار فعلي.
- integration/: مسار دمج وFastAPI. تشغيل محلي للتطوير، مش خدمة إنتاجية معتمدة.

كل فولدر موديل فيه البيانات المتاحة وكود التدريب والأوزان وشرح PDF. المستندات التاريخية والنتائج القديمة لا تتقدم على تنبيه التدقيق الحالي.

## تشغيل التطوير محليًا

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
python -m pytest tests/ integration/tests/ -v
uvicorn integration.api:app --port 8000
```

الـ API للتجربة المحلية. ما تستخدمش تنبؤاته وحدها لقبول إعلان أو رفضه أو الحكم على سعر صفقة. تقييم الرؤية والحالة غير مثبت للإنتاج.

## تدقيق الرؤية من غير تدريب أو قياس أداء

```bash
python vision/audit_integrity.py
python vision/audit_loader.py
```

الفحص الأول يراجع بصمات النسخة المحفوظة ويعيد سجل سلامة البيانات. الثاني يختبر قراءة الملفات مرة واحدة بمحمّل Ultralytics، من غير تحميل أوزان أو حساب mAP. نجاح الفحصين لا يثبت صلاحية البيانات أو استقلالها.

كود إعادة التدريب والحصاد والتنظيف التطبيقي وإعادة بناء بيانات الرؤية مقفول افتراضيًا لحين معالجة النتائج ومراجعة مستقلة. ما تشيلش القفل عشان تحصل على نتيجة أعلى.

## الخصوصية وحقوق الصور

المستودع خاص. الصور الخام لا تتنشر في ديمو عام ولا تتشارك مع جمهور جديد. سجل المصدر لا يساوي إذن استخدام تجاري، ولا يثبت وحده إن الصورة من السوق المصري.
